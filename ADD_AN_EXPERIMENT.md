# Adding an experiment

How to add one test so that it can be graded the same way as the 78 already here. Read [CONTRIBUTING.md](CONTRIBUTING.md) first.

## 1. Pick a family and an ID

Use an existing family folder under [experiments/](experiments/README.md) if one fits. IDs are short and upper-case, such as `XS-REV-1`. Check that the ID is not already in [registry/trial_ledger.csv](registry/trial_ledger.csv).

## 2. Write and freeze the spec

Copy [experiments/_template/spec.md](experiments/_template/spec.md) to `experiments/<family>/<ID>/spec.md` and fill every section: hypothesis, instruments, data and period, the in-sample, out-of-sample and holdout dates, rules, every parameter and its values, costs, the full search grid, the selection rule, the gates and their thresholds, and the decision you will draw from each outcome.

Commit the spec on its own, before any run on the test data. Record its SHA-256 in the spec's first deviations entry:

```
python -c "import hashlib,sys; print(hashlib.sha256(open(sys.argv[1],'rb').read().replace(b'\r\n',b'\n')).hexdigest())" experiments/<family>/<ID>/spec.md
```

## 3. Add the ledger row

Append one row to [registry/trial_ledger.csv](registry/trial_ledger.csv) per search. Columns are `trial_id, programme_or_family, label, n_variants, date, outcome, count_basis, source, publish_class`. `n_variants` is every configuration you will run, and `count_basis` is `exact` when the code enumerates them. `outcome` starts as `RUNNING`.

## 4. Run

Put code in `experiments/<family>/<ID>/code/`, or reuse the shared pieces:

| Need | Use |
|---|---|
| Bar engine with stops, targets and same-bar rules | [audit/engine/nbe.py](audit/engine/nbe.py), tested in [audit/engine/](audit/engine/) |
| Deflated Sharpe and probabilistic Sharpe | [src/dsr.py](src/dsr.py) |
| HistData gold clock fix | [src/clock.py](src/clock.py) |
| Gates, random twins and bootstrap | [audit/phaseE/lib.py](audit/phaseE/lib.py). Its `twin_p` draws a random side for each twin trade, so for long-only rules use a side-matched twin, see RESEARCH_AGENDA.md, item 3 |
| Public data downloads | [scripts/download_data.py](scripts/download_data.py) and [data/manifest.csv](data/manifest.csv) |

Fix every seed. Save raw trades as CSV or JSON next to the summary, so others can recompute the profit factor and trade count.

## 5. Report

Write `experiments/<family>/<ID>/README.md` from [experiments/_template/README.md](experiments/_template/README.md). Report every gate, pass or fail, with trade counts, and the deflated Sharpe at both your own and the full ledger count. Update the ledger row's `outcome`. Add a row to the index table in [experiments/README.md](experiments/README.md).

A note on tooling: in this release, the experiment pages, `registry/experiments.yaml` and the index were generated by private build scripts that are not published, because they read the author's unpublished originals. For new experiments, edit these files by hand as described above.
