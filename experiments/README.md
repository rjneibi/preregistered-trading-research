# Experiments

One folder per audited registry entry, 78 in all. Each page gives what was tested, the instruments and data, the rules, every indicator and parameter value, the costs, the tuning search and how the reported variant was chosen, results with trade counts, the code and how to rerun it, and corrections to the earlier page. Each fact names its source file, and "Not recorded in the published files" marks a gap.

A verdict grades the stored claim, not the strategy. "Configs searched" is counted from the code or results where possible. The ledger count used for the deflated Sharpe is in [registry/trial_ledger.csv](../registry/trial_ledger.csv), and the differences are listed in [registry/ledger_corrections.csv](../registry/ledger_corrections.csv). "Public rerun" says whether the public data is enough to regenerate the result.
